# Zum Hans Worscht — PRDXQ redesign concept

Independent, uncommissioned design concept. It is not the official website and does not imply endorsement or a business relationship.

## Pages
- [Konzept](index.html)
- [Speisekarte](speisekarte.html)
- [Besuch](besuch.html)

## Design direction
Eine moderne Interpretation von Imbisskultur: klare Sprache, kräftiges Curryrot, warme Cremeflächen und ein einfacher Weg zu Menü und Besuch.

## Research reference
https://www.gateway-gardens.de/en/life/

## Evidence and limitations
The Gateway Gardens directory includes Zum Hans Worscht in its English overview, but current location details and menus are not confirmed in this concept. A similarly named website found in search refers to a Bad Nauheim location and should not be assumed to be this location.

The included GitHub Actions workflow deploys the static site to GitHub Pages on pushes to `main`. In repository settings, select GitHub Actions as the Pages deployment source if required.
